## 1. รูปโปรไฟล์ + พื้นหลัง

LINE OA Manager (manager.line.biz) → **ตั้งค่า → ตั้งค่าบัญชี**

- รูปโปรไฟล์ → อัปโหลด `profile.png` (ถ้าเปลี่ยน ต้องรอ 1 ชั่วโมงก่อนเปลี่ยนได้อีก)
- **หน้าโปรไฟล์ → รูปพื้นหลัง** → อัปโหลด `cover.png`
- ข้อความสถานะ (ไม่เกิน 20 ตัวอักษร): `เสนอราคาใน 24 ชั่วโมง`

## 2. ริชเมนู

LINE OA Manager → **หน้าหลัก → ริชเมนู → สร้าง**

1. เลือกเทมเพลต **ขนาดใหญ่** แบบ **"ช่องบนกว้าง 2 + 1 / ล่าง 3"** (5 ช่อง)
   ถ้าไม่มีแบบนี้ ให้เลือกแบบ 6 ช่อง (3×2) แล้วตั้ง action ช่อง A และ B ให้เหมือนกัน
2. **ออกแบบภาพ → อัปโหลดภาพพื้นหลัง** → `richmenu.png`
3. ตั้ง action ตามตาราง
4. ข้อความบนแถบเมนู: `เมนู · ขอใบเสนอราคา`
5. แสดงเมนูเป็นค่าเริ่มต้น: **เปิด**

| ช่อง | ตำแหน่ง (px) | ประเภท | ค่า |
|---|---|---|---|
| A ขอใบเสนอราคา | x 0–1666, y 0–843 | ข้อความ | `ขอใบเสนอราคา` |
| B หมวดสินค้า | x 1666–2500, y 0–843 | ข้อความ | `สินค้า` |
| C โทรหาเรา | x 0–833, y 843–1686 | ลิงก์ | `tel:0642133140` |
| D เว็บไซต์ | x 833–1666, y 843–1686 | ลิงก์ | `https://prime-web-silk.vercel.app` |
| E ติดต่อเรา | x 1666–2500, y 843–1686 | ข้อความ | `ติดต่อ` |

ช่อง A, B, E ส่งคีย์เวิร์ด → ไปเรียกข้อความตอบกลับในข้อ 4

## 6. Flex Message (การ์ด)

LINE OA Manager ส่ง Flex แบบ JSON ไม่ได้โดยตรง ใช้ได้ 2 ทาง:

- **ดูตัวอย่าง / ปรับแก้:** วาง JSON ที่ https://developers.line.biz/flex-simulator/ → Showcase → View as JSON
- **ใช้งานจริง:** ผ่าน Messaging API (ต้องมี Channel access token + webhook) หรือเครื่องมือเสริมที่รองรับ Flex JSON
  ส่ง `flex-products.json` เมื่อลูกค้าพิมพ์ "สินค้า" และ `flex-quote.json` เมื่อพิมพ์ "ขอใบเสนอราคา"

ถ้ายังไม่ใช้ Messaging API ข้อความตอบกลับในข้อ 4 ใช้แทนได้ครบทุกกรณี
